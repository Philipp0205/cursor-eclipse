Cursor for Eclipse

An Eclipse plug-in that runs the Cursor agent inside the IDE over the Agent Client Protocol: streaming chat, tool approvals, and file edits applied through the Eclipse workspace.

Update site

In Eclipse, open Help → Install New Software… and add this location:

https://philipp0205.github.io/cursor-eclipse/p2/

Requirements

  • Eclipse 2025-09 (4.37) or later on Java 21
  • The Cursor CLI on PATH, signed in with agent login
  • Linux: WebKitGTK (for example libwebkit2gtk-4.1-0) for the chat view
