# Cursor for Eclipse

Eclipse plugin that runs [Cursor](https://cursor.com) Agent inside the IDE over [ACP](https://cursor.com/docs/cli/acp) (`agent acp`).

This repository currently contains the **integration plan only**. See [PLAN.md](PLAN.md).

## Intended usage (after implementation)

1. Install [Cursor CLI](https://cursor.com/docs/cli/using) and run `agent login`.
2. Install this feature from the p2 update site (to be published).
3. Open **Window → Show View → Cursor** and chat with the agent against your workspace.
